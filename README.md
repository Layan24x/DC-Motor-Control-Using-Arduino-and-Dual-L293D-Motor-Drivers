# DC Motor Control Using Arduino and Dual L293D Motor Drivers

## Project Overview

This project demonstrates how to control four DC motors using an Arduino Uno and two L293D motor driver ICs in Tinkercad. The motors execute a predefined sequence of movements to simulate the motion of a four-wheel robot.

## Objectives

- Interface four DC motors with Arduino.
- Use two L293D motor drivers to control motor direction.
- Simulate robot movement in Tinkercad.
- Implement sequential motion using Arduino programming.

## Components Used

- Arduino Uno R3
- 2 × L293D Motor Driver IC
- 4 × DC Motors
- Breadboard
- Jumper Wires

## Motion Sequence

The robot performs the following actions automatically:

1. Move Forward
   - All four motors rotate forward for 30 seconds.

2. Move Backward
   - All four motors rotate in reverse for 60 seconds.

3. Turn Right and Left Alternately
   - The robot alternates between right and left turns for 60 seconds by reversing the direction of motors on one side.

After completing the sequence, the program repeats continuously.

## Circuit Design

The circuit was designed and simulated using Tinkercad.

### Main Connections

- Arduino Uno
- Two L293D motor driver ICs
- Four DC motors
- Shared 5V and GND power rails

## Software

- Arduino IDE (Arduino Language)
- Tinkercad Circuits Simulator

## Features

- Control of four DC motors
- Forward and backward movement
- Right and left turning
- Continuous automatic operation
- Simulation using Tinkercad
